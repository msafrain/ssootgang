# ßootgang

A plain white, scrollable boots archive hosted with GitHub Pages and populated from Blogger.

## Content source

- Blog: https://ssootgang.blogspot.com/
- Required Blogger label: `boots`

The JavaScript loader retrieves Blogger posts in batches of 500 and continues requesting later batches until no more posts remain. Each post can display every image embedded in that Blogger post.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `CNAME` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder.
6. Save.
7. In **Custom domain**, enter `ssootgang.com`.
8. Configure the domain DNS records requested by GitHub and enable HTTPS when available.

## Posting workflow

1. Publish a post on Blogger.
2. Add the Blogger label `boots`.
3. Add one or more photographs to the post.
4. The post will appear on ssootgang.com after Blogger updates its public feed and the visitor refreshes the website.
